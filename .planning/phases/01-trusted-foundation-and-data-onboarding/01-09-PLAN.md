## Trust Boundaries
| Boundary | Description |
|---|---|
| browser→user APIs | Caller/body/target identity are untrusted. |
| application service→Better Auth/Prisma | Credential and access lifecycle span sensitive stores. |
## STRIDE Threat Register
| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-01-01 | Elevation | cross-branch assignment | high | mitigate | Resolve canonical location server-side; full resulting assignment validation. |
| T-01-02 | Elevation | direct non-Admin APIs | high | mitigate | `requireCapability` and owner-target guard in every handler/service. |
| T-01-03 | Elevation | retained sessions | high | mitigate | Same transaction for access update/session deletion plus old-cookie tests. |
| T-01-04 | Tampering | workbook poisoning | high | mitigate | Assignments use canonical active locations only. |
| T-01-05 | Tampering/DoS | production reset | critical | mitigate | No reset operation exposed by user APIs. |
| T-01-06 | Elevation | second Admin | high | mitigate | Three-role Zod allowlist, owner-target immutability, DB partial uniqueness. |
| T-01-07 | Elevation | Better Auth overexposure | high | mitigate | Application-owned routes only; public sign-up disabled; no generic Admin client. |
| T-01-08 | Disclosure | temporary password | high | mitigate | Masked request, no response/log/cache echo, Better Auth hashing. |
| T-01-SC | Tampering | dependencies | high | mitigate | Pinned existing Better Auth; no upgrade. |
</threat_model>
