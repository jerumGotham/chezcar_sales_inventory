# Reports Production Spec

**Status:** Accepted scope for simple reports phase
**Last updated:** 2026-08-26
**Source:** Grill-with-docs reports decisions; ADR 0013

## Purpose

Provide simple read-only reports for Admin and Accounting Staff using live persisted data. Reports support business review, manual receipt reconciliation, and Admin inventory review without turning the dashboard into an export surface.

## Access

| Actor | Reports access |
| --- | --- |
| Admin | Sales, Accounting/Reconciliation, Inventory. |
| Accounting Staff | Sales, Accounting/Reconciliation. |
| Stock Staff | No Reports menu access. |
| Branch Staff | No Reports menu access. |

## Global Report Rules

- Reports are read-only.
- Reports query live DB data on every request.
- No saved report snapshots.
- No stored generated PDF files.
- Date filters include Today, Yesterday, This Week, This Month, and custom from/to date.
- PDF export only for Reports.
- UI may include simple charts; PDFs include tables/totals only.
- PDF header includes Chezcar name/logo placeholder, report title, date range, generated by, and generated at.
- Cancelled/voided transactions are excluded from totals and displayed separately.
- No staff ranking/performance report.

## Sales Report

### Summary

- Total sales.
- Transaction count.
- Items sold.
- Totals by branch.
- Totals by date.
- Admin-only branch performance comparison.

### Receipt-Level Detail

- Manual receipt number.
- Branch.
- Staff/encoded by.
- Customer or Guest.
- Items total.
- Downpayment/final payment indicators when the sale came from an order.
- Transaction status.
- Transaction date/time.

## Accounting/Reconciliation Report

### Verification Summary

- Unverified count.
- Verified count.
- Flagged count.
- Counts by branch/date.

### Flagged Detail

- Manual receipt number.
- Branch.
- Encoded by.
- Accounting staff who flagged.
- Mismatch category/reason.
- Notes.
- Date flagged.

## Admin Inventory Report

Admin-only.

### Current Stock Summary

- Product item code and name.
- Category.
- Brand.
- Product status.
- Location.
- On-hand.
- Reserved.
- Available.
- Reorder level.
- Stock status.

### Movement Summary

- Movement totals by date.
- Movement totals by movement type.
- Movement totals by location.
- Movement totals by product.

## Export Requirements

- PDF generation must use server-authorized report data.
- PDF must not include UI-only charts in the first implementation.
- PDF must include selected filters and generated metadata.
- Accounting PDF must not include Admin-only inventory data.

## Acceptance Criteria

1. Stock Staff and Branch Staff cannot access Reports page or report APIs.
2. Accounting Staff cannot access Inventory Report.
3. Date presets and custom date range return consistent live DB results.
4. Sales totals exclude cancelled/voided transactions.
5. Cancelled/voided transactions appear separately when relevant.
6. Sales Report includes summary and receipt-level detail.
7. Accounting Report includes verification counts and flagged mismatch details.
8. Admin Inventory Report includes current stock and movement summaries.
9. PDF export works for each authorized report and includes company header metadata.
10. Reports have no CSV export in the first implementation.
